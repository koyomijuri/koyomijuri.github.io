暦ジュリ

プライバシーポリシー

このページは、YouTube チャンネル「暦ジュリのタイムトラベルVlog」（以下「当チャンネル」）の公式サイトと、当チャンネルの運営者が使うツール「暦ジュリ 分析」での情報の扱いについて定めたものです。

1. このサイトについて

このサイトでは、お名前・メールアドレスなどの個人情報を集めていません。アクセス解析のツールや、広告のための Cookie も使っていません。文字の表示に Google Fonts を使っており、そのために閲覧時の情報が Google に送られることがあります。

2. 「暦ジュリ 分析」について

「暦ジュリ 分析」は、当チャンネルの運営者が自分のチャンネルの数字（再生数・視聴時間・登録者数など）を確認するためだけに使う、個人用のツールです。一般の方には公開していません。

  • 取得する情報: YouTube Data API と YouTube Analytics API を通じて、運営者自身のチャンネルの統計情報を「閲覧のみ」の権限で取得します。動画の投稿・編集・削除はできません。
  • 使い道: 運営者自身が、動画の振り返りと次の企画のために使います。
  • 第三者への提供: 取得した情報を、第三者に売ったり渡したりしません。
  • 保存: 情報は運営者のパソコンの中にだけ保存します。
  • 取り消し: Google アカウントの「サードパーティ アクセス」から、いつでもアクセスを取り消せます。

Google API から受け取った情報の使い方は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。YouTube の情報の扱いには YouTube 利用規約と Google プライバシーポリシーも適用されます。

3. お問い合わせ

このポリシーについてのお問い合わせは、YouTube チャンネルの概要ページからお願いします。

4. 変更

内容を変えたときは、このページを更新します。
